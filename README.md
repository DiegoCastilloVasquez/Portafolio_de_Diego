# Portfolio de Diego - Desarrollador de Software

## 📋 Descripción

Este es mi portfolio personal, yo soy Diego Castillo, desarrollador de software con formación en matemáticas. Este sitio web muestra mis habilidades, proyectos, certificaciones y experiencia en el desarrollo de aplicaciones web, de escritorio y móviles.

**Enlace en vivo:** [https://diegocastillovasquez.github.io/Portafolio_de_Diego](https://diegocastillovasquez.github.io/Portafolio_de_Diego)

## ✨ Características

- **Diseño Moderno y Responsivo:** Interfaz elegante con animaciones suaves y diseño adaptativo para todos los dispositivos
- **Secciones Completas:**
  - **Hero:** Presentación inicial con llamada a la acción
  - **Sobre Mí:** Información personal y formación académica
  - **Habilidades:** Visualización de competencias técnicas con barras de progreso animadas
  - **Proyectos:** Galería de proyectos con filtros por categoría y modales detallados
  - **Certificaciones:** Carrusel animado con 92 certificaciones (haz clic para ampliar)
  - **Contacto:** Enlaces directos a GitHub, LinkedIn y correo electrónico copiable
- **Interactividad:**
  - Navegación suave entre secciones
  - Filtrado de proyectos por categoría (Web, Escritorio, Todos)
  - Modales detallados para cada proyecto
  - Modal de correo electrónico con funcionalidad de copiar
  - Lightbox para certificaciones
  - Animaciones de entrada al hacer scroll
  - Menú hamburguesa para dispositivos móviles
